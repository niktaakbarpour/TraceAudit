# Data access

Research datasets are not distributed in this repository. Obtain access through
the project’s approved York University and dataset channels. Keep raw recordings,
HDF5 archives, videos, images, labels, and human-review materials outside the
Git checkout. The repository `.gitignore` excludes common research-data formats.

The source corpus catalog and derived manifests remain on the approved research
storage. Public or collaborator distribution of those artifacts requires a
separate data-sharing review.
